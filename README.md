# Luna 的童话花园

为安卓平板设计的家庭本地版成长系统。明亮的粉色、淡紫和奶油金童话城堡地图，使用原创 SVG 图形与系统字体，无外部图片或第三方 API。

## 每日任务

| 任务 | 奖励 |
| --- | --- |
| 写一页字 | 1 个皇冠 |
| 读一本故事 | 1 个皇冠 |
| 认字 | 1 个皇冠 |
| 背一首古诗 | 1 个皇冠 |
| 读英语 | 1 个皇冠 |
| 学思维 | 1 个皇冠 |
| 读英语绘本 | 1 根魔法棒 |

每项每天领取一次。认字、英语和思维练习的内容由家长与孩子约定；这里不设置错题或考试记录。每天一个节点，显示当日获得的皇冠、魔法棒。仅当天可以打卡和修正，过去日期只读，每个月切换一个童话场景。

## 心愿与礼盒

- 皇冠兑换心愿，家长可以添加、修改心愿名称、具体约定和价格。未兑现的心愿可取消并返还皇冠，兑现后保留历史。
- 1 根魔法棒抽一次盲盒，皇冠不能抽盲盒，两种奖励不互相兑换。
- 七种卡等概率、可重复：洗碗卡、摆鞋子卡、擦桌子卡、看电视半小时卡、看电视一小时卡、游乐场卡、爬山卡。
- 家务卡是完成一次家务，家长约定适合孩子的范围。出游卡进入待安排清单。完成或使用后家长核销。
- 扣款与抽到的卡片在同一个 IndexedDB 事务里保存，刷新不会重抽，不能取消或退回魔法棒重抽。
- 同一浏览器多个窗口的旧状态提交会被拒绝，避免覆盖数据或重复消费。

## 安装与数据

正式入口：https://jjouc.github.io/luna-growth-world/

安卓平板首次联网打开 HTTPS 网址后，在支持 PWA 的浏览器中选择“安装应用”或“添加到主屏幕”。家长设置中可查看离线状态。之后固定从同一个入口使用。

无需账户和云端数据库。记录保存在当前设备的 IndexedDB，数据库名称为 luna-growth-world，与哥哥的 growth-world 分开。两人的备份标记不同，无法交叉导入。Service Worker 只管理本项目目录和 luna-growth-world 缓存，不删除哥哥的离线文件。

建议每周导出 JSON 备份；换设备时先导出，再到新设备导入。清除网站数据、系统回收存储或设备丢失可能丢失记录；申请持久保存不能代替备份。GitHub Pages 只托管程序文件，不上传孩子的任务记录。家长入口没有密码锁。

## 电脑预览

在本目录运行：

    python3 -m http.server 8766 --bind 127.0.0.1

打开 http://localhost:8766/ 。直接双击 HTML 不支持可靠的本地保存与离线安装。

## 发布

GitHub Pages 选择 main 分支根目录。发布 index.html、style.css、app.js、sw.js、manifest.webmanifest、icon.svg、icon-192.png、icon-512.png 和 .nojekyll。程序支持项目子目录，无需构建。更新时递增 sw.js 中缓存名，并同步 app.js 的离线状态检查。

不要上传孩子的备份、验证脚本和预览截图。
